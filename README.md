# 🖨️ Typography Financial Optimizer 2026

Профессиональный инструмент для финансового планирования и анализа рисков типографии. Программа автоматизирует расчет налоговой нагрузки, определяет точку безубыточности и визуализирует путь к целевой прибыли.

## ✨ Основные возможности
* **Налоговый оптимизатор**: Мгновенное переключение между **ОСН (с НДС 20%)** и **УСН (6% от выручки)** для выбора наиболее выгодной модели налогообложения.
* **Автоматический расчет ФОТ (РБ)**: Введите сумму "на руки", и программа сама рассчитает ФСЗН (34%+1%), Подоходный налог (13%) и Белгосстрах (0.6%).
* **Анализ «Запаса прочности»**: Оценка устойчивости бизнеса к колебаниям рынка с цветовой индикацией статуса (Критический / Норма / Высокий).
* **Интерактивный график**: Визуализация точки безубыточности и четкая маркировка **Целевой чистой прибыли**.
* **Сохранение данных**: Все введенные параметры автоматически сохраняются в `settings.json`.

## 🛠️ Технологии
* **Python 3.13**
* **CustomTkinter**: Современный графический интерфейс в Dark Mode.
* **Matplotlib**: Динамическое построение финансовых графиков.
