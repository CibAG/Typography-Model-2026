# 🖨️ Typography Financial Model 2026

Профессиональный инструмент для финансового планирования и расчета точки безубыточности типографии. Программа автоматизирует расчет налоговой нагрузки на ФОТ и визуализирует финансовые цели.

## 🚀 Основные возможности
* **Расчет точки безубыточности:** Определение минимальной выручки для покрытия всех расходов.
* **Автоматизация налогов (РБ):** Расчет ФСЗН (34%+1%), Подоходного налога (13%) и Белгосстраха (0.6%) исходя из желаемой зарплаты "на руки".
* **Учет специфики:** Поддержка НДС, маржинальности (себестоимости) и лизинговых платежей.
* **Визуализация:** Интерактивный график прибыли с отметкой целевых показателей.
* **Сохранение данных:** Автоматическое сохранение последних введенных параметров в `settings.json`.



## 🛠️ Технологический стек
* **Python 3.11+**
* **CustomTkinter:** Современный графический интерфейс в темной теме.
* **Matplotlib & Numpy:** Математические расчеты и построение графиков.
* **PyInstaller:** Сборка в автономный `.exe` файл.
